# 🎓 **BNCA University Ledger Extraction Project**

This repository contains the **BNCA University Ledger Extraction Project**. The project is designed to automate the extraction, cleaning, and structuring of ledger data from unstructured **PDF files** for **Dr. Bhanuben Nanavati College of Architecture for Women, Pune**. Additionally, it includes the development of an interactive **Power BI** dashboard to visualize **student performance** based on the extracted ledger data.

---

## 📌 **About the Project**

🔹 **Project Title:** BNCA University Ledger Extraction  
🔹 **Role:** Data Analyst   
🔹 **Tools & Technologies Used:**  
   - **Python** (for data extraction, cleaning, and transformation)  
   - **PyPDF2** (for reading and extracting data from PDFs)  
   - **Pandas** (for data manipulation)  
   - **OpenPyXL** (for Excel file export)  
   - **Power BI** (for interactive dashboards and visualizations)  
   - **Regular Expressions** (for data cleaning)  

---

## 💡 **Project Overview**

The **BNCA Ledger Extraction Project** is designed to streamline the extraction of ledger data from **unstructured PDF files**, clean and structure the data into **Excel format**, and visualize student performance using a **Power BI** dashboard. The primary goal was to automate data extraction and improve the efficiency of analyzing and presenting student performance data.

---
## 🛠 **Key Features**
🔹 Automated PDF Data Extraction
Extract ledger data from PDF files using the PyPDF2 library.

🔹 Data Transformation
Cleans and structures the extracted data using Pandas, transforming it into a tabular format.

🔹 Excel Export
Exports the cleaned and structured data to Excel using OpenPyXL.

🔹 Interactive Dashboard
Develops an interactive Power BI dashboard to visualize key performance indicators such as grades, attendance, and performance trends.

🔹 Batch Processing
Supports batch processing of multiple PDF files at once for automated data extraction.

---
## 📝 How It Works
🔹 PDF Extraction
The script reads and extracts text from the PDF files located in the input/ folder using the PyPDF2 library.

🔹 Text Parsing & Data Cleaning
Regular expressions are applied to clean the extracted text and parse key information like transaction dates, student names, and performance scores.

🔹 Data Structuring
The cleaned data is structured into a tabular format using Pandas and saved as an Excel file in the output/ folder.

🔹 Dashboard Creation
The structured data is imported into Power BI, where a dashboard is created to visualize student performance metrics.
